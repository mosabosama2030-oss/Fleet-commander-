# تصميم الأمان والخصوصية — A1-10 (مسودة PROPOSED)

- يحوّل ضوابط `THREAT_MODEL_AR.md` (T-01..T-14) إلى متطلبات تصميم قابلة للاختبار. لم يُنفَّذ أي شيء (NOT RUN).
- يتغير حسب DEC-07 (المصادقة) وDEC-08 (الاستضافة) وDEC-14 (الاحتفاظ).

## 1. المصادقة والجلسات (T-02)
| البند | التصميم المقترح |
|---|---|
| كلمة المرور | hash بخوارزمية حديثة مُملَّحة (Argon2id أو ما يعادله بعد المراجعة)؛ لا نص صريح |
| الرمز | access token قصير العمر + إبطال عند الخروج/تغيير كلمة المرور |
| الحماية من التخمين | rate limit لكل حساب وIP؛ تأخير تصاعدي؛ رسالة خطأ موحدة |
| الاستعادة | رابط بريد لمرة واحدة قصير الصلاحية؛ لا يكشف وجود الحساب |
| Web | كوكي HttpOnly+Secure+SameSite أو رمز في الذاكرة؛ CSRF حسب الاختيار |
| Android | تخزين الرمز في Keystore؛ لا في ملفات عادية |

## 2. التفويض والملكية (T-01، T-09)
- `owner_user_id` من الجلسة فقط؛ الحقول المجهولة في الطلب تُرفض.
- كل استعلام يضيف شرط المالك داخل طبقة المستودع (لا في الـcontroller).
- سجل غير مملوك يرجع 404 مطابقًا لغير الموجود.
- اختبار آلي لكل endpoint بحسابين (T-ISO-01/02).

## 3. المرفقات (T-04)
- التحقق بمحتوى الملف (magic bytes) لا بالامتداد؛ قائمة سماح JPEG/PNG (مقترح، DEC-12)؛ حجم أقصى مقترح 5MB.
- إعادة تسمية بمفتاح عشوائي؛ تخزين خاص؛ لا تنفيذ؛ `X-Content-Type-Options: nosniff`.
- التنزيل بعد فحص الملكية أو رابط موقّع قصير العمر. حساب SHA-256 عند الرفع.

## 4. حماية الواجهة (T-05)
CSP صارمة، ترميز المخرجات، CORS بقائمة سماح لنطاق الواجهة فقط، رؤوس أمان قياسية.

## 5. التسجيل والمراقبة (T-06، NFR-010)
Structured logs مع `request_id`؛ حجب كلمات المرور والرموز والمبالغ التفصيلية؛ AuditEvent لكل كتابة حساسة (تصحيح، تصدير، حذف، تغيير كلمة مرور).

## 6. الأسرار والتبعيات (T-06، T-12)
مدير أسرار؛ لا أسرار في Git؛ فحص أسرار وتبعيات في CI.

## 7. الخصوصية (NFR-009)
- حد أدنى من البيانات؛ لا GPS مستمر (DEC-10)؛ أي موقع عبر ConsentGrant بغرض ومدة.
- تصدير الحساب وحذفه: مسارات مقترحة مع تدقيق؛ مدة الاحتفاظ UNKNOWN (DEC-14).
- لا استخدام لبيانات تطبيقات النقل دون حق وصول رسمي.

## 8. المساعد (T-07، T-08) — D4
أدوات مسماة فقط؛ لا SQL حر؛ محتوى الملفات والنصوص يُعامل بيانات لا تعليمات؛ لا مبالغ من النموذج.

## 9. النسخ الاحتياطي (T-13)
نسخة يومية مقترحة؛ تمرين استعادة فعلي قبل G2؛ RPO/RTO غير معتمدة.

## ربط الاختبارات
T-ISO-01/02، T-AUTH-01/02، T-ATT-01/02، T-LOG-01، T-PRIV-01، T-BKP-01، T-AST-02 (كلها NOT RUN).
