# ADR-FC003 — Backend وقاعدة البيانات والاستضافة

- الحالة: **PROPOSED** — لا قرار معتمد. السلطة: MOSAAB وحده.
- Issue: #4 (FC-003) — المالك: CLAUDE-1 — Base SHA: `08f442e4ba399970712c155eca0c18bf90e883f5`
- التفاصيل والمصادر والأسعار: [BACKEND_PLATFORM_OPTIONS_AR.md](BACKEND_PLATFORM_OPTIONS_AR.md)

## السياق
Captain فردي، Web/PWA ثم Android، Online-only، بريد وكلمة مرور. المحرك المالي حتمي وخارج LLM. A0 غير مكتملة (DEC-03 وDEC-05 وDEC-08 وDEC-09 وDEC-10 مفتوحة حسب وثائق المستودع) وG0/G1 لم تُمنح، فلا كود.

## الخيارات المدروسة
1. Backend: A) Node.js+TypeScript+Fastify، B) Python+FastAPI، C) BaaS على Postgres + خدمة رفيعة للمال.
2. قاعدة البيانات: PostgreSQL (الإصدار 16 أو أحدث؛ 14 منتهي الدعم منذ 2026-11-12).
3. الاستضافة: H1 Render، H2 Supabase، H3 Neon + استضافة منفصلة للخدمة، H4 VPS ذاتي الإدارة (Hetzner).

## التوصية (PROPOSED — ليست قرارًا)
- **Backend A** كمرشح أول: لغة واحدة مع الـPWA (INFERRED)، وإصدارات Node/Fastify المدعومة موثّقة. **B** بديل مقبول إن رُجّح التحليل والتوصيات لاحقًا؛ **C** يوفر وقتًا لكنه يزيد الاعتماد على المزود.
- **PostgreSQL 17 أو 18** مع أعداد صحيحة بالقرش.
- **الاستضافة: لا توصية نهائية** قبل حسم المنطقة والبُعد القانوني (أدناه). الأرخص تقديريًا للبدء: H1 بين $13 و$26 شهريًا، أو H4 بين €5.49 و€8.49 مع عبء إدارة.
