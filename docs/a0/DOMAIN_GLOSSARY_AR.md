# قاموس المجال — A0 (Domain Glossary)

- الحالة: PROPOSED — يعتمد بعد قرارات DEC-03/04/05
- الجلسة: 01

## تصنيف الأدلة
`ACTUAL` مسجل فعليًا · `ESTIMATED` مقدَّر · `INFERRED` مستنتج · `UNKNOWN` غير معروف (تُستخدم في كل مخرجات النظام والمساعد).

## المصطلحات الأساسية
| المصطلح | التعريف المقترح | ملاحظة |
|---|---|---|
| الكابتن (Captain) | المستخدم الفرد صاحب الحساب والسجلات | VERIFIED — قرار بشري |
| الشيفت (Shift) | فترة عمل مسجلة بين بدء وإنهاء، مرتبطة بمركبة | حالاته: DEC-06 |
| ساعة الاتصال (Connected Hour) | الوقت المسجل أثناء الشيفت المفتوح | يُحسب من وقت الخادم |
| الرحلة (Trip) | حدث نقل واحد مسجل | اختياري حسب DEC-02 |
| الإيراد المسجل (Recorded Revenue) | مجموع الإيرادات التي أدخلها الكابتن/استوردها | ليس صافيًا |
| الدخل الإجمالي (Gross) | الإيراد المسجل قبل أي خصم | يعتمد A0-09 |
| الصافي المعروف (Known Net) | الإجمالي − التكاليف والخصومات المعتمدة المسجلة فقط | لا يسمى «ربحًا» قبل اكتمال عناصر التكلفة |
| المستحق (Due) | ما يجب أن يستلمه الكابتن وفق القواعد | غير المدفوع |
| المدفوع (Paid) | ما ثبت استلامه فعليًا | يختلف عن المسجل |
| التسوية (Settlement) | سجل دفعة/تحويل مرتبط بشيفت أو فترة | حالاتها DEC-13 |
| اليوم التشغيلي (Operating Day) | الفترة التي ينسب إليها الشيفت | DEC-04 |
| الكم الفارغ (Empty Distance) | مسافة بلا راكب | يتطلب بيانات مسافة |
| نسبة الخمول (Idle Ratio) | وقت بلا رحلة ÷ وقت الاتصال | من سجلات الرحلات |
| استغلال الشيفت (Utilization) | وقت رحلات ÷ وقت الاتصال | |
| المنطقة (Zone) | خلية H3 أو منطقة يدوية | ALG-11 |
| Cold Start | بيانات غير كافية لتوصية موثوقة | يُعرض UNKNOWN |
| Baseline | خط أساس بسيط للمقارنة قبل أي نموذج | شرط لإعلان نجاح خوارزمية |
| Shadow Mode | تشغيل التوصية دون عرضها للمقارنة بالواقع | |
| Historical Replay | إعادة تشغيل تاريخية خارج العينة | ALG-16 |
| Calculation ID | معرف حساب حتمي يربط الرقم بمعادلته ومدخلاته | يلزم كل ادعاء رقمي |
| Human Director | صاحب القرار النهائي | لا دمج PR دون إذنه |
