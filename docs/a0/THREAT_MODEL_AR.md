# نموذج التهديدات والخصوصية — A0-17 (مسودة)

- الحالة: PROPOSED — تحليل تصميمي؛ لم يُجرَ أي اختبار اختراق (NOT RUN)
- الجلسة: 01

## الأصول
بيانات مالية وتشغيلية للكابتن · هوية الحساب والجلسات · مرفقات (عداد/إيصالات) · بيانات موقع (إن وُجدت) · أسرار الخادم · سجل التدقيق · مخرجات التوصيات.

## حدود الثقة
متصفح/تطبيق Android (غير موثوق) ↔ API (موثوق) ↔ قاعدة البيانات/التخزين ↔ مزودون خارجيون (خرائط) ↔ LLM (غير موثوق للحساب).

## التهديدات والضوابط
| ID | التهديد | الضابط المقترح | اختبار |
|---|---|---|---|
| T-01 | قراءة/تعديل بيانات كابتن آخر (IDOR) | مالك السجل من الجلسة؛ فحص ملكية في كل endpoint | حسابان A/B لكل endpoint |
| T-02 | سرقة/تخمين جلسة | رموز قصيرة العمر، إبطال، rate limit، كوكيز آمنة/Headers | اختبارات مصادقة |
| T-03 | تكرار عملية مالية بعد timeout | Idempotency-Key | إعادة POST |
| T-04 | رفع ملف خبيث | تحقق نوع/حجم/محتوى، تخزين خاص، لا تنفيذ، روابط موقعة | ملفات غير آمنة |
| T-05 | XSS/CSRF/CORS | ترميز مخرجات، CSP، CSRF حسب الجلسة، CORS ضيق | فحص ساكن + E2E |
| T-06 | تسرب أسرار في Git/Logs/العميل | مدير أسرار، فحص أسرار في CI، redaction | فحص CI |
| T-07 | Prompt Injection في نص/ملف يقرؤه المساعد | المساعد بأدوات مسماة فقط، لا SQL حر، بيانات المستخدم تعامل كبيانات | اختبار حقن |
| T-08 | LLM يولد مبلغًا أو مصدرًا | الحساب في المحرك الحتمي؛ كل رقم بـ Calculation ID | اختبار مطابقة |
| T-09 | تصدير بيانات غير مملوكة | فحص الملكية قبل التصدير + AuditEvent | اختبار تصدير |
| T-10 | تتبع موقع بلا موافقة | ConsentGrant؛ لا GPS مستمر | مراجعة |
| T-11 | تلاعب بالسجل بعد الإغلاق | append-only للتصحيح + Audit | اختبار حالة الشيفت |
| T-12 | ثغرات التبعيات | فحص تبعيات في CI | CI |
| T-13 | فقدان بيانات | نسخ احتياطي + تجربة restore فعلية | تمرين استعادة |
| T-14 | WebView غير آمن (إن اختير) | قائمة سماح، تعطيل file://، جسر أدنى | اختبار روابط/أذونات |

## خصوصية
حد أدنى من البيانات · موافقة صريحة للموقع · سياسة احتفاظ وتصدير وحذف حساب (DEC-14 مفتوح) · لا بيانات نقل خاصة بلا حق وصول.

## مخاطر متبقية
قرارات المصادقة (DEC-07) والاستضافة (UNKNOWN) والاحتفاظ تغير الضوابط؛ يراجع النموذج في A1.
