# دورة عمل الكابتن (A0-03) — مسودة

- الحالة: PROPOSED. **A0-03 لا يُغلق** حتى يراجعها الكابتن الفعلي (المدير) ويصحح سيناريو يومه الواقعي.
- كل خطوة مالية معلّمة «قاعدة غير معتمدة».

## المسار الأساسي
1. دخول (FR-001) ← 2. اختيار المركبة (إن تعددت، DEC-01) ← 3. بدء شيفت: قراءة عداد البداية (صورة اختيارية DEC-12)، وقت الخادم (UC-01) ← 4. أثناء العمل: تسجيل إيراد/رحلات (حسب DEC-02) ومصروفات فورية (UC-04) ← 5. استراحة (حالة مقترحة PAUSED؟ — سؤال مفتوح) ← 6. إنهاء: عداد النهاية، مراجعة الملخص (UC-02) ← 7. حساب الخادم «إيراد مسجل» فقط حتى اعتماد DEC-03 ← 8. تسوية/دفعة (DEC-13) ← 9. تقارير (UC-03).

## الحالات الاستثنائية المطلوب تأكيدها من الكابتن
| الحالة | السلوك المقترح (PROPOSED) |
|---|---|
| نسيان إنهاء الشيفت | تنبيه بعد مدة؛ لا إغلاق تلقائي؛ إنهاء بوقت يحدده الكابتن مع AuditEvent |
| انقطاع الشبكة أثناء الإنهاء | لا نجاح وهمي؛ إعادة إرسال بنفس idempotency key |
| شيفت يعبر منتصف الليل | يُنسب ليوم البدء (DEC-04) |
| تغيير المركبة وسط اليوم | ينهي شيفتًا ويبدأ آخر |
| خطأ في عداد/مبلغ بعد الإغلاق | تصحيح append-only بسبب (DEC-06) |
| إدخال رحلة منسية لاحقًا | إضافة بوقت وقوعها مع علامة «أُدخل لاحقًا» |
