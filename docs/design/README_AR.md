# حزمة تصميم Fleet Commander — FC-009

**الحالة: PROPOSED — مرجع تصميم ونموذج HTML تفاعلي قبل التنفيذ.**

هذه الحزمة مخصصة لتجربة **الكابتن الفردي** في Fleet Commander، وليست لوحة إدارة أسطول أو واجهة مشرفين. تتبع اتجاه Calm Command: واجهة عربية RTL واضحة، تشغيل يومي في المقدمة، ومساعد شخصي يشرح الدليل ولا يتجاوز قرار الكابتن.

## شاهد الواجهة

- **[افتح نموذج HTML الكامل والمتجاوب](./fleet-commander-preview.html)** — لوحة رئيسية، تنقل بين الشاشات، إدارة الشيفت، نماذج الرحلات والمصروفات، السجل، التقارير، مركز الذكاء، والإعدادات. التفاعلات محلية للمعاينة فقط ولا تتصل بالخادم.

## حدود مهمة

- **VERIFIED:** المنتج للكابتن الفردي؛ Web/PWA أولًا؛ التشغيل Online-only.
- **VERIFIED:** LLM Gateway موجود في Backend لكنه مغلق افتراضيًا؛ يوجد مسار فهم صوتي قائم على القواعد مع احتياط LLM اختياري.
- **PROPOSED:** الشكل البصري، ترتيب الشاشات، مركز الذكاء الشخصي، والصوت/قراءة الفواتير/ذاكرة التفضيلات كقدرات مستقبلية.
- **UNKNOWN / NOT RUN:** اتصال الواجهة بالخادم، تشغيل نموذج حي، دقة اللهجة على جهاز حقيقي، الميكروفون وTTS، OCR، ذاكرة دائمة، وتجربة الأجهزة الفعلية.
- بيانات HTML توضيحية؛ الأرقام غير المتاحة تظهر كشرطة بدل اختلاق بيانات.
- لا تعرض الحزمة صافي ربح أو مؤشرات مالية نهائية قبل اعتماد قواعد الحساب، ولا تعد بتتبع GPS في الخلفية.
- لا تغيير على `web/` أو Backend أو API أو إعدادات إنتاج ضمن هذه المهمة.

## طريقة المراجعة

افتح ملف HTML في متصفح لمعاينة الواجهة كاملة، أو افتح ملفات SVG لمراجعة الشاشات منفردة. لا تُنقل الشاشات إلى التطبيق ولا تُربط بالخادم قبل اعتماد MOSAAB.

## التحقق

تم جلب ملف HTML من فرع التصميم بعد كتابته والتحقق من وجود عنوان الصفحة، واتجاه RTL، وكود التنقل والتفاعلات. **لم يُنفذ اختبار متصفح حقيقي أو تدقيق وصول آلي أو اختبار على Android**؛ هذه الحالات **NOT_RUN**.
