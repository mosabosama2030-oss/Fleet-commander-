# حزمة تصميم Fleet Commander — FC-009

**الحالة: PROPOSED — مرجع مرئي ومواصفات قبل التنفيذ.**

هذه الحزمة مخصصة لتجربة **الكابتن الفردي** في Fleet Commander، وليست لوحة إدارة أسطول أو واجهة مشرفين. تتبع اتجاه Calm Command: واجهة عربية RTL واضحة، تشغيل يومي في المقدمة، ومساعد شخصي يشرح الدليل ولا يتجاوز قرار الكابتن.

## حدود مهمة

- **VERIFIED:** المنتج للكابتن الفردي؛ Web/PWA أولًا؛ التشغيل Online-only.
- **VERIFIED:** LLM Gateway موجود في Backend لكنه مغلق افتراضيًا؛ يوجد مسار فهم صوتي قائم على القواعد مع احتياط LLM اختياري.
- **PROPOSED:** الشكل البصري، ترتيب الشاشات، مركز الذكاء الشخصي، والصوت/قراءة الفواتير/ذاكرة التفضيلات كقدرات مستقبلية.
- **UNKNOWN / NOT RUN:** اتصال الواجهة بالخادم، تشغيل نموذج حي، دقة اللهجة على جهاز حقيقي، الميكروفون وTTS، OCR، ذاكرة دائمة، وتجربة الأجهزة الفعلية.
- لا تعرض الحزمة بيانات تجريبية كأنها بيانات مستخدم، ولا صافي ربح أو مؤشرات مالية نهائية قبل اعتماد القرارات، ولا تعد بتتبع GPS في الخلفية.
- لا تغيير على `web/` أو Backend أو API أو إعدادات إنتاج ضمن هذه المهمة.

## طريقة المراجعة

افتح SVG مباشرة من GitHub لمعاينة كل شاشة، ثم راجع التوكنز والمواصفة. لا تُنقل الشاشات إلى التطبيق قبل اعتماد MOSAAB؛ بعد ذلك ينفذ مالك Web/PWA المكونات ويربطها بالعقود المراجعة.

## التحقق

تم جلب الملفات بعد كتابتها من فرع التصميم للتحقق من وجودها ومحتواها. لم يُنفذ اختبار متصفح حقيقي أو تدقيق وصول آلي أو اختبار على Android؛ هذه الحالات **NOT_RUN**.
