## عند دخولك أول مرة
1. افتح `AGENTS.md` ثم التعليمات الخاصة بمنصتك (`CLAUDE.md` أو `GROK.md` أو `MANUS.md`). حسابات ChatGPT/Codex تتبع `AGENTS.md`.
2. اقرأ `docs/agents/TEAM_OPERATING_MODEL_AR.md` و`docs/agents/AGENT_TASK_INDEX_AR.md`.
3. افحص آخر حالة حية على GitHub: main، PRs، Issues، branches، SHA.
4. ابدأ المهمة المطابقة لدورك فقط. لا تنتظر إعادة شرح السياق إذا كانت المهمة واضحة.
5. علّق CLAIM على Issue قبل أي تعديل.
6. افحص `session/05-tech-auth-gps` وPR #1 للحصول على الوثائق الأحدث غير المدمجة، وقارنها بـmain. لا تنقلها أو تدمجها تلقائيًا.
7. قدم العمل عبر فرع مستقل وPR Draft، ثم اكتب تقرير التسليم.

## المهام المحجوبة
المعلومات الموثقة في `docs/sessions/SESSION_05_REPORT_AR.md` على الفرع غير المدمج تشمل: مركبة واحدة؛ إدخال الرحلات يدويًا رحلة برحلة؛ الشيفت ينسب ليوم البدء بتوقيت القاهرة ولا فرق سعر ليل/نهار؛ تصحيح Append-only مع سبب وتدقيق؛ بريد وكلمة مرور مع استعادة بالبريد؛ Web/PWA أولًا وAndroid كتغليف لاحق؛ GPS أثناء الشيفت بموافقة صريحة.

تحقق من أحدث سجل قبل الاعتماد؛ هذه البيانات موجودة بفرع غير مدمج وقد تتغير. لا تعتبرها مدمجة في main.

A0 لا تزال غير مكتملة. أمثلة الشيفت وقواعد المال، تصنيفات المصروفات، العملة والتقريب، تفاصيل الاحتفاظ بالموقع، اختيار الخادم/الاستضافة/قاعدة البيانات، وتفاصيل بعض المصادر ما زالت تحتاج حسمًا. لا تنشئ معادلات مالية ولا تخترع إجابات.

## حدود الاستقلالية — مهم جدًا
ملفات التعليمات وGitHub Issues تنظم العمل لكنها لا تشغل نموذج AI من تلقاء نفسها. فتح المستودع لا يوقظ ChatGPT أو Claude أو Grok أو Manus تلقائيًا، وتعليق HANDOFF لا يرسل لهم جلسة تلقائيًا. هذا يحتاج Runtime/Integration منفصلًا لكل مزود، صلاحيات GitHub، وآلية تشغيل/اعتماد واضحة، وربما مفاتيح API وتكلفة. لا توجد في هذا الإعداد أسرار أو مفاتيح مزودين تسمح بادعاء أن التشغيل الكامل unattended قد تم تفعيله.

الآلية المتاحة الآن: MOSAAB يوجه كل حساب مرة واحدة إلى المستودع/Issue؛ الوكيل يقرأ تعليماته ومهمته ويعمل في جلسته؛ ثم يسلم عبر GitHub للوكيل التالي. استمرار العمل بعد انتهاء الجلسة يحتاج أن يبدأ الوكيل التالي أو أن يُربط لاحقًا بمشغل آلي حقيقي.
