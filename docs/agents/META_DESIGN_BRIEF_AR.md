# موجز Meta AI Design Studio — Fleet Commander

## المنتج
Fleet Commander: مساعد تشغيل وذكاء شخصي للكابتن الفردي. نطاق الإصدار الأول: Web/PWA متجاوب؛ Android لاحقًا كتغليف وفق القرار الموثق. النظام Online-only.

## المهمة
إنتاج اتجاه بصري وموجز تصميم، لا كتابة كود المنتج ولا اعتماد الوظائف:
1. Moodboard واتجاه بصري واضح (عملي، احترافي، موثوق، مناسب للاستخدام أثناء التنقل).
2. لوحة ألوان مع حالات نجاح/تحذير/خطر وتباين قابل للقراءة.
3. نظام Typography عربي/لاتيني مع دعم RTL.
4. مقترح Design Tokens: colors, spacing, radius, elevation, typography.
5. تصور الشاشات الأولية: تسجيل الدخول، لوحة الكابتن، بدء/إنهاء الشيفت، الرحلات اليدوية، المصروفات، سجل الشيفت، التقارير، الموافقة على GPS.
6. مكونات: cards, forms, tables/lists, charts, status banners, navigation, empty/error/loading states.
7. أصول مرئية منفصلة بأسماء واضحة وخلفيات شفافة عند الحاجة.

## قيود
- لا تصمم واجهات إدارة أسطول أو مديرين/مشرفين؛ لا تدخل في نطاق Captain الفردي.
- لا تعرض أسعارًا أو صافي ربح أو KPI نهائي قبل اعتماد القواعد المالية.
- لا توحِ بوجود تتبع GPS في الخلفية ضمن PWA؛ يجب إظهار الموافقة وحالة التتبع بوضوح، وعدم ادعاء استمرار غير مضمون.
- لا تجعل شاشة أثناء القيادة تشجع التفاعل؛ قلل الخطوات، وراعِ السلامة وإمكانية الوصول.
- لا تنتج نصوصًا صغيرة أو تباينًا ضعيفًا أو زخرفة على حساب وضوح الأرقام.
- قدم التصميم كمرجع بصري مع المواصفات والأصول، ويحوّله Claude-2 إلى مكونات بعد اعتماد التصميم.
