# واجهة Fleet Commander — Captain Workspace

نسخة معاينة عربية RTL للكابتن الفردي (PROPOSED / Prototype only).

- ثمانية أقسام: الرئيسية، الشيفت، الرحلات، المصروفات، السجل، التقارير، المساعد الشخصي، الإعدادات والخصوصية.
- تنقل سطح المكتب عبر القائمة الجانبية، وتنقل هاتف عبر الشريط السفلي وزر المزيد.
- تصميم Calm Command مستلهم من حزمة التصميم المقترحة في PR #48؛ لا يعني ذلك اعتماد PR أو دمجه.
- لا API أو تسجيل دخول أو تخزين محلي أو GPS أو طلبات شبكة أو مزود LLM أو حسابات مالية.
- مؤشرات الاتصال تخص اتصال الجهاز فقط ولا تؤكد اتصال الخادم.

## تشغيل المعاينة
افتح `index.html` في متصفح حديث. لا حاجة إلى تثبيت حزم أو اتصال بالإنترنت لعرض الأصول المحلية.

## التحقق
`node --check app.js`
`python -m unittest discover -s . -p 'test_*.py' -v`

لم يتم الادعاء باختبار بصري على جهاز Android أو قارئ شاشة فعلي.
