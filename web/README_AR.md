# واجهة Fleet Commander الأولية — FC-WEB-01

## الحالة
**PROPOSED / Prototype only.** هذه ملفات واجهة عرض عربية RTL متجاوبة، وليست إصدارًا تشغيليًا.

## الملفات
- `index.html`: بنية HTML دلالية واتجاه RTL.
- `styles.css`: تصميم متجاوب دون مكتبات أو خطوط خارجية.
- `app.js`: تنقل بين الصفحات ومؤشر اتصال الجهاز.

## التشغيل المحلي
افتح `index.html` مباشرة في متصفح حديث. لا يحتاج المشروع إلى تثبيت حزم أو بناء أو اتصال بمزود خارجي لعرض الواجهة.

## ما يعمل في هذه النسخة
- التنقل بين الرئيسية والشيفت والرحلات والمصروفات والتقارير والإعدادات.
- قائمة جانبية متجاوبة على الهاتف، وإغلاقها بمفتاح Escape.
- مؤشر اتصال الجهاز باستخدام `navigator.onLine`. هذا **لا يثبت** أن الخادم متصل.
- حالات فراغ ورسائل توضح الاعتماديات والقرارات غير المحسومة.

## ما لا يعمل — عمدًا
- لا مصادقة، ولا جمع لكلمة المرور.
- لا API أو Backend أو قاعدة بيانات.
- لا حفظ في `localStorage` أو IndexedDB.
- لا أوفلاين أو Service Worker.
- لا حسابات دخل أو صافي أو رسوم.
- لا GPS أو طلب إذن موقع.
- لا بيانات نموذجية توهم بوجود سجلات حقيقية.

## بوابات الربط التالية
1. عقد API مُراجع ومتوافق مع Backend.
2. جلسة البريد/كلمة المرور ومصدر حالة الشيفت من الخادم.
3. حسم DEC-03/05/09 قبل أي عرض أو حساب مالي.
4. حسم DEC-10 قبل إضافة GPS أو واجهة موافقته الفعلية.

## التحقق
لا يدّعي هذا التسليم اختبار متصفح آليًا أو اختبارًا على جهاز فعلي. يلزم التحقق البصري والوصولي على الهاتف وسطح المكتب قبل اعتماد الواجهة.


## تجهيز PWA — بلا تكلفة وبلا Offline

**PROPOSED / تجهيز محلي فقط:** أضيف Manifest وأيقونات محلية بمقاسات 192×192 و512×512، مع أيقونة maskable، لتجهيز الواجهة كمرشح للتثبيت من المتصفح على Android بعد استضافتها عبر HTTPS.

- لا توجد استضافة أو عملية نشر ضمن هذا التغيير.
- لا يوجد Service Worker أو Offline cache؛ المنتج يظل Online-only.
- لا يوجد APK أو Android signing أو Play Store package.
- لا توجد مصادقة أو API أو قاعدة بيانات متصلة بهذه الواجهة.
- لا يمكن إعلان أن التثبيت يعمل فعليًا قبل استضافة HTTPS وفحص خيار التثبيت وتجربة التشغيل على جهاز Android حقيقي.
