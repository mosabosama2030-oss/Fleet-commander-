# Fleet Commander

مساعد تشغيل وذكاء شخصي للكابتن الفردي.

## نقطة الدخول للوكلاء
- اقرأ [AGENTS.md](AGENTS.md) قبل أي عمل.
- ابدأ من [دليل التشغيل الأول](docs/agents/START_HERE_AR.md).
- راجع [نموذج الفريق](docs/agents/TEAM_OPERATING_MODEL_AR.md).
- اختر المهمة المطابقة لدورك من [فهرس التكليفات](docs/agents/AGENT_TASK_INDEX_AR.md).
- التزم بقالب [Pull Request](.github/PULL_REQUEST_TEMPLATE.md).

Captain فردي، Web + Android، Online-only. تحقق من سجل القرارات الأحدث قبل أي تنفيذ؛ لا تعتبر المسودات أو الفروع غير المدمجة جزءًا من main تلقائيًا.
